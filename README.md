# OTF — onythefamily

เว็บไซต์ทำเนียบสมาชิก OTF โหมดไฟล์เว็บแบบไม่ใช้ระบบหลังบ้านหรือ Firebase

## เปิดเว็บ
เปิด `index.html` หรือ `members.html` ในเบราว์เซอร์ แล้วไปที่หน้า Members เพื่อดูและเพิ่มรายชื่อ

## เพิ่มสมาชิก
กรอกชื่อ เลือกตำแหน่ง (MEMBERS, LEADER, BIGSUPPORT หรือ OWNER) และใส่ฉายาได้ตามต้องการ จากนั้นกด “เพิ่มชื่อ” รายชื่อจะบันทึกใน LocalStorage ของเบราว์เซอร์เครื่องนั้น

ข้อมูลใน LocalStorage จะไม่ซิงก์ไปเครื่องหรือเบราว์เซอร์อื่น หากล้างข้อมูลเว็บไซต์ รายชื่อที่เพิ่มไว้ในเครื่องนั้นอาจหายไป
